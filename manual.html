Tsunami Manager — Quick Reference

Everything you need to turn a folder of samples into a Tsunami-ready microSD card. The manager runs entirely in your browser: no sound is uploaded anywhere.

Five-minute start

  1. Open the manager in Chrome or Edge (needed to write straight to the card and for MIDI/serial; other browsers download a ZIP instead).
  2. Check Settings → Firmware: Stereo or Mono must match the firmware on your Tsunami.
  3. Drop samples on the Pads, or use Import folder… for a whole sample pack (one bank per folder).
  4. Click a pad to hear it and open it in the Inspector on the right, where you can trim, fade and level it.
  5. Go to Export, fix anything the preflight flags, then Write to SD card… and pick the card's root folder.
  6. Eject the card, put it in the Nutella and press RESET. The blue LED blinks 3 times when it finds the card and files.

New here? Load demo kits on the empty Pads page fills a project with synthesized drums to explore.

Track numbers & banks

The Tsunami plays files by number (1–4096). Everything in the manager is a view of that number:

Triggertrack = bank × 16 + trigger
MIDI notetrack = MIDI bank × 128 + note
  • Kit pads 1–8 are Kick, Snare, Open hat, Closed hat, Clap, Perc 1, Perc 2, Cymbal. Drop several files on one of them and they're sorted onto the right pads by name; extra kicks, snares… continue on the same pad in the next banks (up to 8 banks per drop).
  • Triggers 15 and 16 are Bank Down / Bank Up in new projects, so each bank is a 14-sound kit. Numbering skips the 15/16 slots, since no trigger can reach them.
  • Inbox = imported sounds without a number. They aren't written to the card until you drag them onto a pad or number them on the Tracks page.
  • Bank names are your labels for trigger banks (e.g. 808 Kit). Folder import fills them in from folder names.

Importing

Reads WAV, AIFF/AIFF-C (all common encodings), and whatever else the browser decodes: FLAC, MP3, Ogg, M4A… Everything is converted to 44.1 kHz 16-bit WAV on export.

Folder import

  • Reads subfolders up to 8 levels deep. At most 500 audio files per import; scanning stops at 4000 files. Import big libraries one subfolder at a time.
  • Left out automatically: hidden and system files (._*, .DS_Store, __MACOSX), files that aren't audio, empty or broken files. Files over 50 MB and duplicates (same name and size) are left out unless you switch them on.
  • One bank per folder puts each folder in the next empty bank, starting from a bank you choose; banks that already hold tracks are skipped, so nothing is replaced. Rename the banks in the dialog. Or choose Numbered in order or Inbox.

Chrome may ask to “upload” a picked folder. Nothing leaves your computer; that's just the browser's wording for giving the page access.

Editing sounds (Inspector)

Select a sound on Pads, Tracks or the MIDI map and the Inspector opens on the right. Edits never touch your original files; they're applied when you export.

  • Trim & fades: drag the handles on the waveform, or type times. Auto-trim cuts silence and adds a 5 ms fade-out.
  • Reverse, Loop preview, and Original for A/B against the untouched file.
  • Level: peak or loudness (RMS) normalisation, then gain on top. Double-click a slider to reset it.
  • Pan (stereo firmware): balance-style, written into the WAV, never adds clipping.
  • Channels: mono firmware sums or picks left/right; stereo firmware keeps as is, sums, picks a side or swaps. Mono sources become stereo for the stereo firmware.
  • MIDI playback: one-shot or loop, and the output, both written into the file name (_S2, _L3). They only matter when MIDI starts the sound.

Triggers & presets

FunctionWhat the trigger does
NormalPlays bank × 16 + trigger (follows Bank Up/Down).
Next / Previous / RandomSteps or picks at random through a track range (Random never repeats twice in a row).
Pause / Resume / StopActs on every track in a range.
Volume Up / Down1 dB per trigger on an output, or all outputs.
Bank Up / Down, MIDI Bank Up / DownShift the trigger bank (16 tracks) or MIDI bank (128 tracks).
Synced SetMono firmware only: starts up to 8 tracks sample-locked on consecutive outputs.

Type: Edge = one-shot, Level = plays while the gate is high, Latch = first trigger starts, next stops. Options: retrigger, polyphonic, loop, lock voice, trigger gain, output.

Built-in presets

All default · Drum kits + bank switch · Gate / sustain · Round-robin pairs · Stem launcher · One output per trigger. The last two ask for Stereo or Mono. The stereo stem launcher plays 4 stereo stems on pairs 1/2–7/8 (triggers 1–4, with 5/6/7 = stop/pause/resume); the stereo firmware has no Synced Set, so patch one gate to inputs 1–4 to start them together.

Your own presets

  • Triggers → Save as preset… or Presets → From current project stores all 16 triggers with their names.
  • On the Presets page, type a name for each trigger (shown on pads, tiles and the output grid), edit settings, pick Stereo/Mono, then Apply to project. Undo with ⌘Z.
  • Presets live in this browser. Use Export / Import file… (.json) to back them up or move them to another computer.

Writing the card

  1. Preflight lists errors and warnings, some with a one-click fix: set debounce to 5 ms, make T15/T16 the bank switches, or lower the peak target to −6 dBFS. Tracks sitting on control-trigger slots are listed so you can renumber them on the Tracks page.
  2. Write to SD card… (Chrome/Edge): pick the card's root folder. Unchanged files are skipped, same-number conflicts are cleaned up, and every file is read back and verified. Optionally remove other numbered WAVs from the card.
  3. Or Download ZIP and copy its contents to the card's root, or tsunami.ini only.
  4. Eject properly, insert, press RESET (no power cycle needed).

Use class 4 or 10 non-UHS cards formatted FAT16/FAT32. Three quick blinks after RESET = card and files found; one long blink = card unreadable or no WAVs.

Card doctor

Open a card (or any folder) to see it the way the Tsunami does. It finds duplicate track numbers, wrong formats, metadata before the audio (the classic “file won't play”), wrong channel count for the firmware, lower-case MIDI flags, WAVs in subfolders and macOS ._ files.

  • Repair fixable files in place, losslessly where possible.
  • Convert mono → stereo for the stereo firmware: overwrite, write copies to another folder, or download a ZIP.
  • Remove macOS/system items, write the project's tsunami.ini to the card, download a report, or Import into project.

Live (hardware)

  • MIDI → Nutella: audition tracks on the module through its MIDI input, send Program Change for MIDI banks, and output volume / attack / release CCs.
  • Serial → Tsunami (advanced): through the serial header with a 3.3 V FTDI adapter: version and track count, play/stop, banks, volumes, and sending a trigger's settings to test them before writing the card.

Card rules the manager follows

  • WAV, 16-bit PCM, 44.1 kHz; mono files for the mono firmware, stereo for the stereo firmware. Exports use a plain 44-byte header, so there's never metadata before the audio.
  • Files sit in the card's root, and each name starts with the track number: 0017_Snare.wav. An optional _L/_S + output right after the number sets MIDI loop/output (1–8 on mono firmware, 1–4 on stereo): 0017_S2 Snare.wav.
  • tsunami.ini is written the way the Robertsonics Configurator writes it, and only for settings that differ from the defaults.
  • Voices: original/Qwiic board 32 mono or 18 stereo, Qwiic 25 board 25 mono or 13 stereo. Synced sets: mono firmware, at most 8 tracks.

Tips & troubleshooting

  • Can't write to the card / no MIDI: use Chrome or Edge on a desktop computer.
  • Looks like an old version after an update: hard refresh with ⌘⇧R (Ctrl+Shift+R).
  • Where is my work? Projects autosave in the browser, audio included, per web address. Clearing site data deletes them, so use Settings → Save project bundle as a backup and export your presets.
  • Fast rolls and ratchets miss hits: set debounce to 5 ms (Export offers it as a fix).
  • Distortion when layering: the Tsunami mixes voices digitally. Normalise to −6 dBFS instead of −1 when you stack many sounds.
  • A file won't play: open the card in the Card doctor; it's usually metadata before the audio or the wrong channel count.
  • Switching firmware: put the .hex on the card as tsunamix.hex, hold USER and tap RESET until the LED is solid, then tap RESET again. Change Settings → Firmware to match.
